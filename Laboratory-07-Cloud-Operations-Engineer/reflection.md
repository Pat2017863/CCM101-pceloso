# Mission 7 Reflection

This laboratory activity helped me understand why monitoring is an important part of cloud computing. I learned that deploying an application is not enough because the server and application must also be monitored to make sure they continue working properly.

Checking the host server's resources is important even when containers are running perfectly. Containers depend on the host's CPU, RAM, and disk storage. If the server runs out of memory or storage, the applications inside the containers may become slow or stop working. Checking these resources before a large increase in website traffic helps engineers identify possible problems early.

The `docker logs` command is useful when a user reports that they cannot log into a web application. It allows an engineer to inspect the messages generated by the application and look for errors related to requests, authentication, or server processing. These messages can provide clues about what happened and help the engineer investigate the problem.

Logs and metrics provide different types of information. Logs record individual events, requests, and errors, while metrics show numerical measurements such as CPU usage, memory consumption, and network traffic. Using both helps an engineer understand what the application is doing and how well it is performing.

Large enterprise companies may use monitoring tools such as Prometheus and Grafana to monitor thousands of containers. Prometheus can collect and store performance metrics, while Grafana can display the collected information in dashboards. Alerts can also notify engineers when resource usage becomes unusually high or a service becomes unavailable.

Through this activity, I improved my ability to use Linux commands, deploy a Docker container, test a web server, and inspect application logs. I also learned that troubleshooting should be based on actual evidence instead of guessing. In the future, I want to practice more monitoring commands and learn how to configure automated alerts so that problems can be detected and resolved more quickly.
