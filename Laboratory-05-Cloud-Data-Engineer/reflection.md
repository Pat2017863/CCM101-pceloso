# Mission Reflection

## 1. Why is object storage better suited for storing millions of photos?

Object storage is better for storing millions of photos because it is designed for large amounts of files and unstructured data. Each photo is stored as an object with information about the file. It can also grow as more photos are added, making it useful for photo-sharing applications.

## 2. How did Docker make it easier to deploy MinIO?

Docker made it easier because I did not need to install MinIO manually on the Ubuntu server. I only needed to use a Docker command to create and run the MinIO container. Docker also made it easier to manage the server and its settings.

## 3. What is a bucket?

A bucket is a container used to store and organize objects in cloud storage. In this activity, I created a bucket named `client-photos`. I then uploaded a sample file called `sample-photo.txt` into the bucket.

## 4. How can large companies prevent data loss?

Large companies can protect their object storage data by keeping multiple copies of their files. They can also use backups, replication, and different servers or locations. These methods help protect data if a physical server fails.
