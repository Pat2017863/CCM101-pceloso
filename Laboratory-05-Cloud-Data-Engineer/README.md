# Laboratory Activity 5 - The Cloud Data Engineer

## Mission Overview

In this laboratory activity, I learned about cloud storage and deployed an S3-compatible object storage server using MinIO and Docker. I created a storage bucket named `client-photos` and uploaded a sample file through the MinIO web console.

## Objectives

- Differentiate between Block, File, and Object Storage.
- Deploy MinIO using Docker.
- Access the MinIO web console using port forwarding.
- Create a cloud storage bucket.
- Upload an object to the bucket.
- Document cloud storage operations using Markdown.
- Update my GitHub Cloud Computing Portfolio.

## Tools Used

- KillerCoda Ubuntu Playground
- Docker
- MinIO
- GitHub
- Web Browser
- Linux Command Line
- Markdown

## Skills Learned

- Understanding different types of cloud storage
- Deploying applications using Docker
- Working with MinIO object storage
- Creating and managing storage buckets
- Uploading objects to cloud storage
- Using Linux commands
- Documenting cloud computing activities
- Using Git and GitHub for a cloud computing portfolio
