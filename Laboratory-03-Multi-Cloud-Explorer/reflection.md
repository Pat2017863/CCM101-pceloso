# Mission Reflection

## 1. Which cloud platform impressed you the most?

The cloud platform that impressed me the most was Google Cloud Platform. What stood out to me was its range of services and the way these services can be used to solve different business requirements. Before completing this activity, I mainly thought of cloud computing as virtual servers and storage. After researching the platforms, I realized that cloud providers offer many more services for networking, databases, security, artificial intelligence, and application development.

## 2. What similarities exist among AWS, Azure, and GCP?

AWS, Azure, and GCP all provide similar categories of cloud services. All three platforms offer virtual machines, object storage, networking, databases, identity management, and Kubernetes services. They also allow organizations to scale resources according to their requirements instead of depending completely on physical infrastructure.

## 3. How do business requirements influence cloud platform selection?

Business requirements are important because there is no single cloud provider that is automatically the best for every organization. A company needs to consider its budget, existing technologies, workload, scalability requirements, security needs, and technical skills. For example, an organization heavily dependent on Microsoft technologies may benefit from Azure, while an AI-focused organization may prefer Google Cloud.

## 4. What did you learn from acting as a Cloud Solutions Consultant?

I learned that choosing a cloud provider requires more than simply comparing the names of the services. A Cloud Solutions Consultant needs to understand the client's actual problem and then match the problem with appropriate cloud services. This activity helped me think about cloud computing from a business and technical perspective.

## 5. How has your GitHub Cloud Computing Portfolio improved after completing this mission?

My GitHub Cloud Computing Portfolio became more organized because I added a complete laboratory focused on multi-cloud technologies. It now contains research, comparisons, recommendations, Linux investigation results, and screenshots as evidence of my work. The activity also helped me practice using Markdown and Git commands to document and manage my work.
