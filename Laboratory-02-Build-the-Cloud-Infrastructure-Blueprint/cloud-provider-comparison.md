# Guide Questions

### 1. Which cloud provider offers the broadest range of services?

**AWS** is often considered to offer one of the broadest ranges of cloud services. It provides many options for computing, storage, networking, databases, security, AI, and other cloud technologies.

### 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?

I would recommend **Microsoft Azure** because it is designed to work well with Microsoft products and services. It also integrates with tools such as Windows Server, Microsoft 365, and Active Directory.

### 3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?

**Google Cloud Platform (GCP)** is widely recognized for its AI and machine learning capabilities and its strong support for Kubernetes. Google also created Kubernetes, making GCP a popular choice for containerized applications.

### 4. What similarities did you observe among the three cloud providers?

All three providers offer similar core services, including **Compute, Storage, Networking, and Identity and Access Management (IAM)**. They also provide security, databases, AI/ML, monitoring, and other services for building and managing cloud applications.
