# Laboratory 02 - Build the Cloud Infrastructure Blueprint

## Mission Overview
The mission of Laboratory 02 is to build a basic cloud infrastructure blueprint and understand how different cloud components work together. The activity focuses on planning and organizing the resources needed to create a functional cloud environment.
## Objectives
To understand the basic components of cloud infrastructure.
To identify the resources needed in a cloud environment.
To create a simple cloud infrastructure blueprint.
To practice using Linux commands related to the laboratory activity.
To understand how cloud resources communicate and work together.
