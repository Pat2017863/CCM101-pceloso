1. **Which cloud infrastructure component do you think is most important? Why?**
   I think the **server or virtual machine** is the most important component because it provides the computing resources needed to run applications and services. Without it, the other cloud components would not have a main environment to operate in.

2. **How does Linux support cloud computing?**
   Linux supports cloud computing because it is stable, flexible, and commonly used for servers. It also provides many useful command-line tools that allow users to manage files, services, networks, and other cloud resources efficiently.

3. **Why is technical documentation important before deploying infrastructure?**
   Technical documentation is important because it serves as a guide for setting up the infrastructure. It helps prevent mistakes, makes the process easier to understand, and allows other people to follow the same steps if they need to maintain or troubleshoot the system.
