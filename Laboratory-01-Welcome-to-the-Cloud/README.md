# Mission 1 – Welcome to the Cloud

## Mission Overview

This laboratory activity introduced me to a cloud-based Linux environment and the basic responsibilities of a cloud infrastructure engineer.

## Objectives

- Access a cloud-based Linux environment.
- Explore the Linux operating system.
- Gather system information.
- Organize files and directories.
- Create a GitHub repository.
- Document technical activities using Markdown.

## Activities Performed

I accessed the KillerCoda Linux Playground, created a Linux user, checked system information, created directories and Markdown files, and prepared my GitHub Cloud Computing portfolio.
